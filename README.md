💰 Finance Tracker








A modern web application to track your daily expenses and manage your budget. Built with Spring Boot, Thymeleaf, and MySQL. Features a dark mode with gold accents for a premium look.

✨ Features

Add, edit, and delete daily expenses.

Set and monitor your budget.

View all transactions in a clean table format.

Responsive UI with glassmorphism effect.

Hover effects and gold highlights for better UX.

🛠 Tech Stack

Backend: Java, Spring Boot

Frontend: Thymeleaf, HTML, CSS (Glassmorphism + Dark Theme)

Database: MySQL

Build Tool: Maven

⚡ Installation

Clone the repo:

git clone <your-repo-url>
cd finance-tracker


Configure database in application.properties:

export DB_URL=jdbc:mysql://localhost:3306/finance_db
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD




Run the application:

mvn spring-boot:run


Open in browser:

http://localhost:8080
